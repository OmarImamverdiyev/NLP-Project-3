# Task3

This folder contains Task3 for training and analyzing **GloVe** embeddings on the main dataset in `Corpora/news/`.

The implementation uses the original C code from:

- https://github.com/stanfordnlp/GloVe

Local clone location used by this task:

- `Task3/glove`

## Run

From project root:

```powershell
./venv/Scripts/python.exe Task3/task3.py
```

## Outputs (`Task3/output/`)

- `task3_report.md`: parameter choices, synonym quality discussion, vector arithmetic and visible patterns.
- `synonyms.tsv`: top-5 similar words for 10 query words.
- `similar_word_math.tsv`: equations on similar-word vectors (`delta`, midpoint-neighbor behavior).
- `vector_equations.tsv`: analogy-style equation results and expected-word rank.
- `relation_patterns.tsv`: cosine similarity between relation vectors.
- `training_corpus.txt`: tokenized corpus generated from `content_only.csv`.
- `vocab.txt`: vocabulary generated by `vocab_count`.
- `cooccurrence.bin`: raw cooccurrence binary.
- `cooccurrence.shuf.bin`: shuffled cooccurrence binary.
- `vectors.txt`: trained GloVe vectors in text format.
